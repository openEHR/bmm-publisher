2+^h|*BMM_ASSIGNMENT*

2+a|Statement type representing an assignment from a value-generating source to a writable entity, i.e. a variable reference or property.

2+|Inherits: xref:{class_bmm_routine_body}[BMM_ROUTINE_BODY], xref:{class_bmm_statement_item}[BMM_STATEMENT_ITEM], xref:{class_bmm_statement}[BMM_STATEMENT], xref:{class_bmm_simple_statement}[BMM_SIMPLE_STATEMENT]

2+h|*Attributes*

|*target*: `xref:{class_el_instantiable_ref}[EL_INSTANTIABLE_REF]` [1..1]
a|The target variable on the notional left-hand side of this assignment.

|*source*: `xref:{class_el_expression}[EL_EXPRESSION]` [1..1]
a|Source right hand side) of the assignment.
