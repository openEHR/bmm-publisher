2+^h|*P_BMM_SCHEMA_DESCRIPTOR*

2+a|Concrete descendant of `BMM_SCHEMA_DESCRIPTOR` that provides a way to read an ODIN or other similarly encoded P_BMM schema file.

2+|Inherits: xref:{class_bmm_schema_descriptor}[BMM_SCHEMA_DESCRIPTOR]

2+h|*Attributes*

|*bmm_schema*: `xref:{class_p_bmm_schema}[P_BMM_SCHEMA]` [0..1]
a|Persistent form of model.

|*bmm_model*: `xref:{class_bmm_model}[BMM_MODEL]` [0..1]
a|Computable form of model. +
_Inherited from xref:{class_bmm_schema_descriptor}[BMM_SCHEMA_DESCRIPTOR]_

|*schema_id*: `xref:{class_string}[String]` [1..1]
a|Schema id, formed by 

`\{BMM_DEFINITIONS}.create_schema_id(
  meta_data.item(\{BMM_DEFINITIONS}.Metadata_model_publisher),
  meta_data.item(\{BMM_DEFINITIONS}.Metadata_schema_name),
  meta_data.item(\{BMM_DEFINITIONS}.Metadata_model_release)`

e.g. `openehr_rm_1.0.3`, `openehr_test_1.0.1`, `iso_13606_1_2008_2.1.2`. +
_Inherited from xref:{class_bmm_schema_descriptor}[BMM_SCHEMA_DESCRIPTOR]_

|*meta_data*: `xref:{class_hash}[Hash]<xref:{class_string}[String],xref:{class_string}[String]>` [1..1]
a|Table of `{key, value}` of schema meta-data, keys are string values defined by `\{BMM_DEFINITIONS}.Metadata_*` constants. +
_Inherited from xref:{class_bmm_schema_descriptor}[BMM_SCHEMA_DESCRIPTOR]_

|*includes*: `xref:{class_list}[List]<xref:{class_string}[String]>` [0..1]
a|Identifiers of schemas included by this schema. +
_Inherited from xref:{class_bmm_schema_descriptor}[BMM_SCHEMA_DESCRIPTOR]_

|*is_top_level* (): `xref:{class_boolean}[Boolean]` [1..1]
