2+^h|*TERMINOLOGY*

2+a|Container for code sets and/or vocabularies that belong to a given logical terminology.

2+h|*Attributes*

|*name*: `xref:BASE:foundation_types:primitive_types.adoc#_string_class[String]` [1..1]
a|Name of this terminology.

|*language*: `xref:BASE:foundation_types:primitive_types.adoc#_string_class[String]` [1..1]
a|Language of this terminology, as an ISO:639 2-letter code.

|*code_sets*: `xref:BASE:foundation_types:structure_types.adoc#_list_class[List]<xref:TERM:terminology_package.adoc#_code_set_class[CODE_SET]>` [0..1]
a|Code sets in this Terminology.

|*vocabularies*: `xref:BASE:foundation_types:structure_types.adoc#_list_class[List]<xref:TERM:terminology_package.adoc#_terminology_group_class[TERMINOLOGY_GROUP]>` [0..1]
a|Vocabularies of coded terms in this terminology.

|*version*: `xref:BASE:foundation_types:primitive_types.adoc#_string_class[String]` [0..1]
a|Version of this instance of the terminology.

|*date*: `xref:BASE:foundation_types:time_types.adoc#_iso8601_date_class[Iso8601_date]` [0..1]
a|Date of issue of this version of the terminology.
