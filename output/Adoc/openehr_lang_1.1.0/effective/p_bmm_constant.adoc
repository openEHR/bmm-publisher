2+^h|*P_BMM_CONSTANT*

2+a|Persistent form of a BMM constant, i.e. a named, typed literal value defined on a class.

2+|Inherits: xref:{class_p_bmm_model_element}[P_BMM_MODEL_ELEMENT]

2+h|*Attributes*

|*documentation*: `xref:{class_string}[String]` [0..1]
a|Optional documentation of this element. +
_Inherited from xref:{class_p_bmm_model_element}[P_BMM_MODEL_ELEMENT]_

|*name*: `xref:{class_string}[String]` [1..1]
a|Name of this constant within its class. Persisted attribute.

|*type*: `xref:{class_string}[String]` [1..1]
a|Type name of this constant, as a simple class name. Persisted attribute.

|*value*: `xref:{class_string}[String]` [0..1]
a|The literal value of this constant, in its persisted (serialised) form. Persisted attribute.
