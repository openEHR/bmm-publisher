|*Schema_name_delimiter*: `xref:{class_string}[String]{nbsp}={nbsp}"::"` [1..1]

|*Package_name_delimiter*: `xref:{class_string}[String]{nbsp}={nbsp}"."` [1..1]

_Inherited from xref:{class_bmm_definitions}[BMM_DEFINITIONS]_

2+h|*Attributes*

|*schema_directories*: `xref:{class_list}[List]<xref:{class_string}[String]>` [0..1]
a|List of directories where all the schemas loaded here are found.

|*all_schemas*: `xref:{class_hash}[Hash]<xref:{class_string}[String],xref:{class_schema_descriptor}[SCHEMA_DESCRIPTOR]>` [0..1]
a|All schemas found and loaded from `schema_directories`. Keyed by schema_id, i.e. model_publisher '_' schema_name '_' model_release, e.g. openehr_rm_1.0.3.

|*valid_models*: `xref:{class_hash}[Hash]<xref:{class_string}[String],xref:{class_bmm_model}[BMM_MODEL]>` [0..1]
a|Top-level (root) models in use. Keyed by logical schema_name, i.e. model_publisher '_' model_name, e.g. "openehr_rm".
