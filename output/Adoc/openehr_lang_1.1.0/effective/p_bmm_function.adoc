2+^h|*P_BMM_FUNCTION*

2+a|Persistent form of a BMM function (routine) definition within a class definition.

2+|Inherits: xref:{class_p_bmm_model_element}[P_BMM_MODEL_ELEMENT]

2+h|*Attributes*

|*documentation*: `xref:{class_string}[String]` [0..1]
a|Optional documentation of this element. +
_Inherited from xref:{class_p_bmm_model_element}[P_BMM_MODEL_ELEMENT]_

|*name*: `xref:{class_string}[String]` [1..1]
a|Name of this function within its class. Persisted attribute.

|*aliases*: `xref:{class_hash}[Hash]<xref:{class_string}[String],xref:{class_string}[String]>` [0..1]
a|Optional alias names for this function, keyed by alias. Persisted attribute.

|*is_abstract*: `xref:{class_boolean}[Boolean]` [0..1]
a|True if this function is abstract in its class, i.e. has no implementation. Persisted attribute.

|*parameters*: `xref:{class_hash}[Hash]<xref:{class_string}[String],xref:{class_p_bmm_function_parameter}[P_BMM_FUNCTION_PARAMETER]>` [0..1]
a|Formal parameters of the function, keyed by parameter name. Persisted attribute.

|*pre_conditions*: `xref:{class_hash}[Hash]<xref:{class_string}[String],xref:{class_string}[String]>` [0..1]
a|Optional pre-condition assertions on this function, keyed by tag. Persisted attribute.

|*post_conditions*: `xref:{class_hash}[Hash]<xref:{class_string}[String],xref:{class_string}[String]>` [0..1]
a|Optional post-condition assertions on this function, keyed by tag. Persisted attribute.

|*result*: `xref:{class_p_bmm_type}[P_BMM_TYPE]` [0..1]
a|Type definition of the function result, if any (absent for procedures). Persisted attribute.

|*is_nullable*: `xref:{class_boolean}[Boolean]` [0..1]
a|True if the result of this function is allowed to be Void (null). Persisted attribute.
