2+^h|*BMM_STRING_VALUE*

2+a|Meta-type for a literal String value, for which `_type_` is fixed to the `BMM_TYPE` representing `String` and `_value_` is of type `String`.

2+|Inherits: xref:{class_bmm3_bmm_literal_value}[BMM_LITERAL_VALUE], xref:{class_bmm3_bmm_unitary_value}[BMM_UNITARY_VALUE], xref:{class_bmm3_bmm_primitive_value}[BMM_PRIMITIVE_VALUE]

2+h|*Attributes*

|*value_literal*: `xref:{class_string}[String]` [1..1]
a|A serial representation of the value. +
_Inherited from xref:{class_bmm3_bmm_literal_value}[BMM_LITERAL_VALUE]_

|*value*: `xref:{class_string}[String]` [1..1]
a|Native String value.

|*syntax*: `xref:{class_string}[String]` [0..1]
a|Optional specification of formalism of the `_value_literal_` attribute for complex values. Value may be any of `json &#124; json5 &#124; yawl &#124; xml &#124; odin &#124; rdf` or another value agreed by the user community. If not set, `json` is assumed. +
_Inherited from xref:{class_bmm3_bmm_literal_value}[BMM_LITERAL_VALUE]_

|*type*: `xref:{class_bmm3_bmm_simple_type}[BMM_SIMPLE_TYPE]` [1..1]
a|Concrete type of this literal. +
_Inherited from xref:{class_bmm3_bmm_primitive_value}[BMM_PRIMITIVE_VALUE]_
